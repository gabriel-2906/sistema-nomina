# Sistema de Nómina - Actividad Unidad 3

Proyecto Java orientado a objetos para la Actividad Unidad 3.

Tecnologías: Java 17, Maven, JUnit 5, IntelliJ IDEA y Git/GitHub.

La aplicación maneja empleados asalariados, por horas, por comisión y temporales. Incluye deducciones, beneficios, validaciones y pruebas unitarias.

Nota: la actividad menciona ARL, pero no proporciona porcentaje o fórmula; por ello no se inventa un valor.
